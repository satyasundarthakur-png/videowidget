# videowidget

A browser-based video and audio toolkit powered by ffmpeg.wasm. All processing
happens locally in the browser — no uploads, no server, no API keys.

## Development

You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
